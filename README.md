## 📌 О проекте

Цель проекта — разработать модель, определяющую класс вина по его химическим характеристикам.

Используется встроенный датасет **Wine** из библиотеки `scikit-learn`.

**Характеристики датасета:**

- 178 образцов вина
- 13 числовых признаков
- 3 целевых класса
- Задача: многоклассовая классификация

## 🧠 Машинное обучение

В проекте реализованы и сравнены два алгоритма:

- **Decision Tree Classifier** — классификация с помощью решающего дерева.
- **Logistic Regression** — линейный классификатор с регуляризацией.

Для логистической регрессии используется `Pipeline`, объединяющий стандартизацию признаков через `StandardScaler` и обучение классификатора.

**Этапы ML-процесса:**

1. Загрузка и подготовка данных.
2. Разделение Train/Test в пропорции 80/20 со стратификацией.
3. Обучение моделей.
4. Пятикратная кросс-валидация.
5. Сравнение результатов по Accuracy.
6. Обучение выбранной модели на тренировочной выборке.
7. Проверка на тестовых данных.
8. Сохранение обученного Pipeline через `joblib`.

## 📊 Результаты

| Модель | Cross-Validation Accuracy |
|---|---:|
| Decision Tree | ≈ 91,60% |
| **Logistic Regression** | **99,31%** |

**Результат выбранной Logistic Regression:**

| Метрика | Значение |
|---|---:|
| Train Accuracy | 100% |
| Test Accuracy | 97,22% |
| Правильные ответы на Test | 35 из 36 |

Логистическая регрессия показала более высокую среднюю Accuracy в проведённой кросс-валидации.

*Примечание: результаты получены на небольшом учебном датасете и не гарантируют аналогичное качество на произвольных новых данных.*

## 🚀 Запуск проекта

### Локальный запуск

Клонировать репозиторий:

```bash
git clone https://github.com/stop3xx67/PROJECT.git
cd PROJECT
```

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустить предсказания:

```bash
python predict.py
```

При необходимости заново обучить модель:

```bash
python train.py
```

### 🐳 Запуск через Docker

Собрать Docker-образ:

```bash
docker build -t wine-classifier:1.0 .
```

Запустить контейнер:

```bash
docker run --rm wine-classifier:1.0
```

Контейнер загрузит сохранённую модель и выведет предсказанные классы вин.

## 🔮 Использование модели

После обучения модель сохраняется в `model.pkl`.

Файл `predict.py` загружает сохранённый Pipeline и классифицирует вина из `new_wine.csv`.

Входные данные должны содержать **13 числовых признаков** с теми же названиями, что и при обучении, без целевого столбца `target`.

Пример входного файла содержит несколько образцов исходного датасета и предназначен для демонстрации работы предсказаний.
